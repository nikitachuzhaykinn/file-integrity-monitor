# 🛡️ FIM Project (File Integrity Monitor)
Система мониторинга целостности файлов. Приложение отслеживает изменения в файловой системе, вычисляет хеши файлов и сохраняет их в базовую линию (baseline). Для защиты базовой линии от подмены используется криптографическая подпись.

## 📋 Основные возможности
- Рекурсивное сканирование директорий и анализ файлов.
- Вычисление криптографических хешей для контроля целостности.
- Создание, обновление и проверка состояния файлов на основе `baseline.json`.
- Защита `baseline.json` с помощью цифровой подписи (асимметричное шифрование).
- Логирование работы программы в директорию `logs/`.

## 📂 Структура проекта

```text
FIM_Project/
├── core/                   # Основной модуль с бизнес-логикой
│   ├── __init__.py
│   ├── baseline.py         # Работа с базовой линией (создание, загрузка, сравнение)
│   ├── hasher.py           # Алгоритмы хеширования файлов
│   ├── scanner.py          # Сканирование файловой системы
│   └── signature.py        # Генерация и проверка цифровой подписи
├── keys/                   # Хранение ключей шифрования (генерируются через keygen.py)
│   ├── private_key.pem     # Закрытый ключ (для подписи)
│   └── public_key.pem      # Открытый ключ (для проверки подписи)
├── logs/                   # Директория для логов
├── test_folder/            # Тестовая директория для проверки работы системы
│   ├── data.csv
│   ├── document.txt
│   └── notes.txt
├── .gitignore              # Исключения для Git
├── config.py               # Конфигурационный файл
├── keygen.py               # Утилита для генерации пары ключей
├── main.py                 # Точка входа в приложение
├── README.md               # Документация проекта
└── requirements.txt        # Зависимости проекта
```
*Примечание: Файлы `baseline.json` и `baseline.json.sig` создаются автоматически в корне проекта при его работе и не хранятся в репозитории (добавлены в `.gitignore`).*

## 🚀 Установка и запуск

1. Клонируйте репозиторий и перейдите в папку проекта:
   ```bash
   git clone <ссылка_на_репозиторий>
   cd FIM_Project
   ```
2. Создайте виртуальное окружение и активируйте его:
   ```bash
   python -m venv venv
   # Windows:
   venv\Scripts\activate
   # Linux/macOS:
   source venv/bin/activate
   ```
3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
4. Сгенерируйте ключи для подписи базовой линии:
   ```bash
   python keygen.py
   ```
   *Ключи сохранятся в папку `keys/`.*
5. Запустите приложение:
   ```bash
   python main.py
   ```

## ⚙️ Конфигурация

Настройки проекта хранятся в `config.py`. Вы можете изменить следующие параметры:
- Пути к директориям для сканирования (по умолчанию `test_folder/`).
- Алгоритм хеширования (например, SHA-256, SHA-512).
- Пути к файлам ключей и базовой линии.

## 🔑 Безопасность и `.gitignore`

В файле `.gitignore` уже настроены следующие исключения, критически важные для безопасности проекта:
- **`keys/private_key.pem`**: Закрытый ключ добавлен в исключения. **Никогда не коммитьте его в публичные репозитории!** Компрометация ключа позволит злоумышленнику подделать базовую линию.
- **`baseline.json` и `baseline.json.sig`**: Файлы базовой линии добавлены в исключения, так как они генерируются автоматически на каждом устройстве.
- **`logs/` и `__pycache__/`**: Системные и временные файлы исключены из репозитория.
